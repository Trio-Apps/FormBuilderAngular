SQL Query Guide
Use SQL Query when dropdown values need stronger logic, joins, filters, or when the source data comes from Form Builder submissions rather than a direct mapped table.
  • Return two main columns: one for the stored value and one for the displayed text.
  • Then map them below using Value Path and Text Path.
  • This is the recommended path when testers expect data from created forms or submission records.
Example shape: SELECT Id, Name FROM Tbl_User WHERE IsActive = 1
Example for advanced scenarios: join submission tables or filter by active business rules, then expose the result as Id and Name.
